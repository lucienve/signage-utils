# Project Context

This file summarizes the current state, architecture, design decisions, and status of the `signage-utils` repository.

---

## 1. System Architecture & Components

The `signage-utils` project is a hub-and-spoke digital signage platform designed to display content on PiSignage boards at a fixed **1920x1080 resolution (16:9)**. 

The architecture consists of:
- **Frontend Displays (HTML/CSS/JS):** HTML views that display the signage content. They use massive fonts and high-contrast styling for billboard readability.
- **Backend Proxies (PHP):** Local PHP proxy endpoints that handle incoming requests from the frontend, query external APIs (Google Sheets, NWS, PurpleAir, WeatherFlow), cache responses, and return JSON data.
- **Cache Layer:** Local JSON cache files generated by the proxies to handle external API rate limits and ensure offline functionality.

### Key Pages and Proxies
- **Menu Board:** [menu.html](../menu.html) / [menu_proxy.php](../menu_proxy.php)
- **GoBoard Message Carousel:** [goboard.html](../goboard.html) / [goboard_proxy.php](../goboard_proxy.php)
- **Garbage Day Schedule:** [garbage_day.html](../garbage_day.html) / [garbage_day_proxy.php](../garbage_day_proxy.php)
- **Events Calendar:** [events.html](../events.html) / [events_proxy.php](../events_proxy.php)
- **Live Weather Board:** [weather_live.html](../weather_live.html) / [weather_proxy.php](../weather_proxy.php)
- **Weather Forecast & Alerts:** [weather.html](../weather.html) / [nws_forecast_proxy.php](../nws_forecast_proxy.php) & [nws_alerts_proxy.php](../nws_alerts_proxy.php)
- **Master Admin sheet:** Links to a Google Sheet that controls menu, goboard, and garbage day override data.

---

## 2. Shared Logic and Libraries

- **`proxy_helper.php`:** Shared utilities including `fetch_with_cache` (cURL execution and stale-while-revalidate caching) and `clear_cache_if_requested` (resilient on-demand cache file deletion).
- **`GarbageDayCalculator.php`:** Encapsulates the logic for calculating Gold Key garbage pickup days, shifting dates for standard holidays (Memorial Day, Labor Day, New Year's, July 4th, Christmas), and processing overrides from the Google Sheet.
- **`js/` Assets:** Shared JS logic (`goboard.js`, `menu.js`, `weather.js`) exported for both browser use and Node/Jest testing.

---

## 3. Testing Environment

- **PHPUnit:** Used to run backend PHP unit tests (under `tests/php/`).
- **Jest:** Used to run frontend JavaScript unit tests (under `tests/js/`).

---

## 4. Maintenance & Operations

- **Dependabot:** Configured to automatically check and update dependencies weekly for `npm`, `composer`, and `github-actions` ecosystems. The configuration is stored in [.github/dependabot.yml](../.github/dependabot.yml).
